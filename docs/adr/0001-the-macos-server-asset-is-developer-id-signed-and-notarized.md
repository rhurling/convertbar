# The macOS server asset is Developer ID–signed and notarized

The darwin-arm64 `convertbar-server` binary runs under a LaunchAgent and reaches LAN hosts through the `ssh` it spawns. macOS local network privacy applies to launchd agents (only daemons, root, and tools run from Terminal or an SSH session are exempt), treats the agent as the responsible code for its children, and keys the grant on the code signature (Apple TN3179). An ad-hoc signature changes with every build, so each release would drop the grant and block every LAN ssh until someone clicks the alert again. CI therefore signs the asset with the same Developer ID identity as the `.dmg` and notarizes it. Rejected: shipping it ad hoc and asking the host to exempt its LAN through `AllowedEthernetLocalNetworkAddresses`, which needs sudo and a reboot and lifts the check for every program on the machine.
