## New findings

1. **[Low] acl-auditor drifted behind the B6 grant trim.** `.claude/agents/acl-auditor.md:18` still lists autostart and window-state as expected frontend plugins, and the line-19 mapping example cites `enable` → `autostart:allow-enable` — a grant B6 removed (autostart is now wholly Rust-side, commands/settings.rs:140-141; the only frontend plugin imports are updater/process, src/pages/SettingsPage.tsx:4-5). Failure scenario: an auditor run anchored on that example treats an autostart/window-state frontend call as the norm and recommends re-adding the removed grants, or reports phantom "unused" expectations. Additionally, TRIAGE B12's bullet claims the ACL-exemption notes were added to "CLAUDE.md / acl-auditor / add-tauri-plugin", but the app-defined-`#[tauri::command]` exemption landed only in CLAUDE.md:25 and add-tauri-plugin SKILL.md:16 — acl-auditor has only the generic backend-only rule (line 23), while its step 2 (line 15) still says to collect `invoke("...")` calls; an auditor could flag app commands as MISSING permissions. Report-only agent, so impact is wasted cycles/false positives, not breakage.

2. **[Low] Four dead frontend plugin npm deps.** package.json still depends on `@tauri-apps/plugin-autostart`, `@tauri-apps/plugin-dialog`, `@tauri-apps/plugin-notification`, and `@tauri-apps/plugin-window-state`, none of which is imported anywhere under src/ (grep confirms; only plugin-updater and plugin-process are used). B6 removed `@tauri-apps/plugin-fs` but left these. Harmless at runtime (tree-shaken), but they misstate the frontend surface to anyone (or any agent) auditing from package.json.

3. **[Low] check-version-sync.sh has no `stop_hook_active` guard.** Now that the hook blocks Stops (exit 2), a drift Claude cannot immediately resolve (e.g. a deliberately mid-bump working tree when the user says "leave it") can re-block every subsequent Stop; the documented Stop-hook pattern is to read `stop_hook_active` from stdin JSON and exit 0 when it is true to break the loop. D7 accepted occasional false-positive blocking, but the loop-guard omission goes beyond the accepted risk. One-line fix: `jq -e '.stop_hook_active == true' >/dev/null 2>&1 <<<"$(cat)" && exit 0` (or equivalent) before the checks.

None was in B12's scope (TRIAGE refs only :108,:109), so these are carryovers, not regressions.
